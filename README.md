# Karolina Vasilenko — GitHub Pages HTML

Это статическая HTML-версия актуального сайта из Lovable.

## Структура
- `index.html` — весь сайт, стили и интерактивность внутри одного файла.
- `images/karolina.jpg` — актуальная фотография.

## Публикация на GitHub Pages
1. Создайте/откройте репозиторий `finance`.
2. Загрузите `index.html` и папку `images` в корень репозитория.
3. Settings → Pages → Source: `Deploy from a branch`.
4. Branch: `main`, Folder: `/ (root)` → Save.
5. Сайт будет доступен по адресу `https://karolinavasilenko.github.io/finance/`.

Node.js не требуется.
