# Сайт Каролины Василенко — GitHub Pages

Эта версия сайта работает без Node.js, npm, React и Vite.

Файлы:
- `index.html` — структура и тексты сайта
- `style.css` — дизайн и адаптация
- `script.js` — мобильное меню и раскрытие тарифов
- `images/karolina.jpg` — фотография

## Публикация на GitHub

1. Создайте новый репозиторий на GitHub.
2. Выберите `Public`, если хотите использовать бесплатный GitHub Pages.
3. Откройте репозиторий.
4. Нажмите `Add file` → `Upload files`.
5. Загрузите содержимое этой папки: `index.html`, `style.css`, `script.js` и папку `images`.
6. Нажмите `Commit changes`.
7. Откройте `Settings` → `Pages`.
8. В `Build and deployment` выберите `Deploy from a branch`.
9. Branch: `main`, Folder: `/ (root)`.
10. Нажмите `Save`.

После публикации GitHub покажет адрес сайта.
